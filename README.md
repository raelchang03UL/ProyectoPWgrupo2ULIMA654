# ULimeñitaPlay

University web development project built with React and TypeScript. The application is a streaming platform prototype with user-facing views, navigation between stream categories, profile features and a virtual store flow.

## Stack

- React
- TypeScript
- Vite
- React Router
- Bootstrap
- CryptoJS

## Main features

- Client-side routing for the main application views
- Stream and category pages
- User profile and registration views
- Virtual store with payment result flows
- Stream configuration interface

## Run locally

```bash
npm install
npm run dev
```

The project was developed as part of a web programming course at Universidad de Lima.
